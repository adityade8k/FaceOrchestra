# Historical arrangement sources

`composition.json` in the parent directory is the sole editable catalog definition. The layout versions here are immutable source evidence for its `sourceCompositionHash` chain, not alternate selectable songs. Their bytes and embedded hashes remain unchanged. `references.json` resolves former hash filenames and content hashes to retained files, relative to the composition directory. Other file references inside these snapshots also resolve from that directory (approved arrangements and normalized MIDI).

The version 5 hash-named file duplicated the canonical definition and was removed. The canonical definition records its previous hash in `compatibility.recordingHashes`. The source preview filenames identify externally supplied proposals; the approved local copies preserve their accepted musical content.
